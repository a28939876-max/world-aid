# 案例三：微软把它做成了 skill / Microsoft Made It a Skill

> 需求：部署 Azure OpenAI 模型——选区域、定容量、建 deployment 这套繁琐流程。
> 预期：顶多找到些零散的教程笔记。

## 世界给了什么

**微软官方出品的 `deploy-model` skill**，完成度远超预期：

- 17 个文件的完整工程：三套子流程（快速预设 / 完全自定义版本与 SKU / **跨区域容量发现与排序**）
- PowerShell 和 Bash 双版本脚本，按意图自动路由
- MIT 许可，明确写了"什么时候不要用我"（边界声明）

一个插曲：搜索返回的 8 条结果**全是这同一个 skill 的转载拷贝**，分散在各家合集与市场仓库里——有的转载连 `license: MIT` 和出品方信息都删掉了。管线把拷贝群归成一族、认出微软官方仓才是源头，装的是原版。安检 17 个文件零命中，落盘即用。

## 启示

1. **大厂在把自家产品能力打包成 skill 发布**——你以为要读半天文档手搓的流程，出品方可能已经替你封装好了，而且质量是产品级的。
2. 转载满天飞的生态里，"找到"只是一半，**认出正主**是另一半：装官方源头版本，许可证、更新、出处都跟得上。
