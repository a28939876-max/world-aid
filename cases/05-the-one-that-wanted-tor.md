# 案例五：差点选了那个"功能最全"的 / The One That Wanted Tor

> 需求原话：「把一个 YouTube 视频转成文字」。

## 先把这一片翻全

这个需求太普通了，普通到我差点又自己去 GitHub 搜。这回先让 world-aid 找。两组关键词下去（"download youtube video transcript" 和 "youtube subtitle to text"），回来 13 个候选。

13 个不是 13 种。world-aid 先归了一遍族，剩下 9 个真正不一样的实现：

| 实现 | 星 | 特点 |
|---|---|---|
| michalparkola/tapestry-skills 的 youtube-transcript | 430⭐ | 头部，这一族下面还挂着 4 个转载拷贝 |
| b33eep | 54⭐ | 顺手把视频关键帧也抽出来 |
| jpoutrin | 13⭐ | 存成干净的文本文件 |
| nguyenngothuong | 9⭐ | 自动翻成越南语 |
| modbender 的 youtube-transcript-tor | 7⭐ | 走 Tor 代理"绕过 IP 封锁" |
| 另有 jina 极简版等几个 | — | 各管一摊 |

光把这一片找全、看清谁跟谁其实是一回事，就是 world-aid 干的头一件事。那 4 个转载要是不归族，我得挨个点开才发现是同一个东西。

## 那个看着最唬人的

剩下几个各有各的侧重。有一个特别扎眼，描述里写着"用 Tor 代理绕过 IP 封锁"。听着像功能最全的那个，下字幕还能防封，我差点就挑它了。

点开一看就不是那么回事。它是个土耳其人写的，注释全是土耳其语。下个字幕而已，它要我先装 Tor 把网络绕一圈，中间还得拿管理员权限改系统、起服务。它存文件的地方写死了，写的是某个云端机器人的目录，跟我这台电脑根本不挨着。

我让本机的 codex 把代码读了一遍。它说没发现偷文件、碰密码这些事，不过提了个醒：这脚本会自己拿管理员权限去起一个 Tor 服务，等于没问我一声就动了系统。这东西其实是给跑在云服务器上的机器人用的，绕 Tor 是为了躲开 YouTube 封 IP。

跟我想要的不是一回事。我就想在自己电脑上下个字幕，它却要我装 Tor、动系统、往一个我这儿不存在的目录里写。

## 启示

1. **找得全，才看得出"最唬人的"不等于"最适合我的"。** 那个 Tor 版本听着功能最强。要是我只搜到它一个，或者它正好排在前面，我大概率就装了。是把同一片东西摊开看，才发现它解决的是别人的问题。
2. **归族不只是去重，是让你看清光谱。** 13 个收成 9 个不同实现，每个侧重一眼就分得出：要纯文本的、要翻译的、要抽帧的、要防封的。挑哪个，看你到底要哪样。
3. 星高不代表对口。头部那个 430⭐ 是给一整套知识库流程配的，我只想要个干字幕，反而是低星里有更趁手的。

## 数据来源

- 本篇是众多实际找寻记录里挑出的典型之一。
- `search_skills.py "download youtube video transcript"` → 13 候选 9 族；那个 Tor 版本走 `codex_review.py` 深审，判 REVIEW（脚本会 `sudo systemctl start tor`）。
